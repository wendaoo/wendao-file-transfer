## 在本工作区运行

工具链已安装在工作区 ../.local-tools；脚本自动识别，不替换系统 Node。

```bash
cd /你的项目位置/wendao-file-transfer
scripts/local/run.sh build
scripts/local/run.sh start
scripts/local/run.sh package
```

首次安装依赖使用 `scripts/local/run.sh install`。迁移到其他电脑时，先准备 .nvmrc 指定的 Node、npm 8.16.0 和 Yarn 1.22.22。

本机首次下载遇到 Node 16 证书校验错误，使用系统受信任公开证书补充 NODE_EXTRA_CA_CERTS 后安装成功，没有关闭证书校验。其他环境如遇同类问题，应使用所在环境可信 CA，不提交本机证书文件。

## 构建限制

这是恢复旧项目的本地开发基线，不是已完成现代化升级的正式发行版。保留 Electron 18 和原有依赖，以便区分原始行为与后续修改。

当前仍有 Sass `/` 除法弃用警告、旧依赖 peer dependency 警告；首次启动日志中观察到 identifier.json 尚未创建的提示，但界面正常渲染。后续应完善初始化与回归测试。未把警告视为已修复。
