# ADB 文件管理与表头修复

2026-09-21

连接时优先选择唯一一台已授权的 USB ADB 设备，目录浏览、存在性检查、上传、下载、创建文件夹、重命名和删除统一经过 ADB。未安装 ADB 或没有已授权 USB 设备时，继续使用设置中选择的 Kalam / Legacy MTP。多台已授权 USB 设备会提示用户仅保留目标设备，不自动猜选。传输开始后的错误不会触发 MTP 重试。

当前 ADB 管理范围为 `/sdcard` 内部共享存储，不包含外置 SD 卡和应用私有目录。开启 USB 调试并授权本电脑即可使用；MTP 回退仍要求手机选择文件传输模式。未对所有手机测试充电模式下的 ADB 可用性。

目录查询在一次远程命令内批量 stat，避免每个文件单独启动进程。路径以 NUL 分隔，避免空格、引号或换行破坏解析。共享存储本身不允许的文件名会由设备返回错误；不自动更改文件名。目录复制补建空文件夹，保留原有覆盖确认。当前传输进度若没有 ADB 百分比输出，则显示活动进度，进程成功退出才标记完成。

表格增加自动填充列，并保证最小宽度为内容区域宽度。标题背景和底部边线不会因缩窄列宽而中断。保留列宽拖拽、灰色滚动条和滚动时显示。

## 验证

- OPPO PLJ110，macOS 13 Intel：678 项根目录读取约 767ms。
- 独立测试目录：16MiB 随机文件及中文、空格、单引号文件名，文件夹上传约 486ms、下载约 500ms，SHA-256 一致。重复上传未产生额外目录嵌套，空目录保留，重命名成功。测试目录已清理。
- 通过界面 dragover/drop 事件上传 1,440,000 字节文件：约 2.34 秒完成上传并刷新 678 项目录，出现进度弹窗，两端哈希一致，测试文件已清理。此时间包含拖拽延迟、界面更新与目录刷新，不能直接当作 USB 带宽。
- 880 / 1280 / 1500 像素窗口及缩窄列宽验证，全部表头单元格背景一致，填满内容区，右侧 8px 为同色滚动条轨道。
- verify-adb-protocol.cjs：路径约束、远程引号、特殊名称、隐藏项、符号链接过滤、空目录及损坏数据。
- verify-adb-routing.cjs：两种 MTP 设置下 ADB 优先、无 ADB 回退、传输失败不重试。回退路由以测试替身验证；没有再次复测已知卡住的旧 MTP 上传。
- verify-native-queue.cjs：原生调用串行与重复释放保护。

以上速度为本次连接和负载下的样本，不代表所有设备或持续传输性能。
