# 2026-09-22 更新记录

> 根据本次会话及当日开发、验收记录汇总。反复微调的样式以当日最终值为准；代码完成与真机验证结果分开记录。

## 文件列表与目录导航

- 列表和网格改为只渲染可见区域及缓冲区，减少大目录的组件和 DOM 开销；排序、选择仍覆盖整个目录。
- 增加按设备、模式、存储和路径隔离的短期目录缓存：有效期 5 秒、最多 12 个目录。手动刷新及文件操作使缓存失效。
- 增加请求序号，防止较慢的旧查询覆盖最新目录；优化进入、返回及滚动复位。
- 统一工具栏、列表与表头视觉，默认将富余宽度分配给文件名，保留可调整列宽和全宽背景。
- 真机样本：Pictures 首次约 470ms、根目录约 612ms；缓存命中后约 187ms／146ms。678 项目录的列表实际只渲染约 29 行。未取得严格同环境改动前基准，不宣称确定加速倍数。

## 手机与 Finder 双向拖拽复制

- 修复从设备文件列表拖出到 Finder 无法复制的问题：通过 macOS 原生文件承诺，在 Finder 接收后下载并交付文件，无需预下载或二次拖动。
- 支持列表／网格中的多选文件、文件夹以及包含空目录的目录树；拖拽执行复制，保留源文件。
- 修复电脑拖入依赖历史拖拽状态、全局队列及延迟触发的问题；落下时保存文件集合、目标路径和设备身份，移除 200ms 延迟。
- 完善传输中防重复操作、断连或设备变化检查、同名处理、取消和失败清理。
- 增加原生双架构拖拽模块并纳入构建流程；传输状态文案默认改为中文。
- 真机集成回归覆盖两个文件和一个文件夹、中文空格名、零字节文件、空目录、哈希一致性、同名取消及临时文件清理。
- 验证调用了实际拖入处理函数和 AppKit 文件承诺委托；未自动执行 Finder 的真实鼠标手势，也未完成 Kalam／Legacy 真机拖出回归。

- 预览容器按设备尺寸／实时画面比例变化；窗口内全屏继续适配实时横竖屏。

## 两级全屏、画质与功耗策略

- 修复绿色窗口按钮显示缩放加号的问题：停止使用 DOM 全屏，保留窗口内预览覆盖层和 macOS 原生全屏能力。
- 最终交互：点击预览下方“全屏”先铺满当前窗口，再点击左上角绿色按钮进入 macOS 原生全屏；退出原生全屏后仍保留窗口内展开状态。
- 画面右上角提供“退出全屏”，支持 Esc 返回普通布局。
- 小窗采用最长边 1200px、最高 15fps、目标码率 4Mbps；全屏使用设备原生分辨率、目标码率 12Mbps，帧率上限由 20fps 提升至 30fps。
- 窗口最小化时停止投屏和解码，恢复后仅重新开启原先已打开的预览。
- 针对闪烁，先移除画质切换时重复出现的连接提示，调整合成层及原生窗口底色。用户仍反馈闪烁后，进一步加入上一帧覆盖画布，覆盖分辨率重置和原生全屏动画，待新画面完成绘制后撤下。
- 高清切换仍可能重建编码会话，短暂停留在上一帧；未承诺无停顿切换。

## APK 拖拽安装与提示框

- 支持将单个本机 APK 拖入设备预览区，使用 ADB 安装到当前设备；入口适用于未开启投屏、实时投屏及全屏预览状态。
- 使用 `adb install -r` 直接覆盖已有应用并保留应用数据，不增加安装前的“已安装”确认；用户确认保留此行为。
- 增加文件类型、普通非空文件、目标设备连接及 USB 调试授权检查；防止同一设备重复并发安装，安装超时为 5 分钟。
- 预览内显示安装中、成功或失败原因。提示框最终左／下／右间距均为 12px、圆角 16px、无描边；完成按钮为“知道了”，悬停时显示淡蓝背景并提亮文字，过渡为 150ms。
- 移除预览区下方常驻的“拖入 APK 到预览区即可安装”说明，保留拖拽安装入口。
- 修复开发窗口界面热更新后主进程未加载安装接口的问题：重启旧开发进程，实际调用确认 `preview:install-apk` 已注册并返回参数校验结果。
- 自动化验证覆盖指定设备、含中文／空格／特殊字符的文件路径、无效文件、未授权／离线、安装失败、超时及并发限制；初始功能的本地构建与 ESLint 检查通过。用户随后提供截图显示 APK 已安装到 PLJ110；尚未独立完成所有投屏模式下的真实拖拽回归。

- 缩略图最长边 160px；最多 2 个并发读取、128 项内存缓存，按设备、路径、文件大小及修改时间区分缓存；单图读取上限 20MiB、超时 15 秒，超过限制回退图标。不写入设备文件，也不向设备目录导入临时文件。
- 新增 `scripts/local/verify-thumbnails.cjs`，验证设备隔离、特殊字符路径、大小上限、缓存失效、重复请求合并、失效连接及并发限制，全部通过；相关 ESLint 和本地构建通过，最后的 24px gap 修正通过 ESLint 及运行中样式检查。

- 已重启开发窗口加载新增接口。未重新打包 DMG；HEIC、RAW 及其他不支持解码的格式仍显示图标，全屏与旋转场景尚未完成本轮真机回归。
