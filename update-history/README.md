# 更新记录维护约定

- 以项目所在时区 Asia/Shanghai 的自然日归档，文件名为 `YYYY-MM-DD-update-history.md`。
- 完成项目修改时同步更新当天文件；同一天合并追加，跨天新建。没有修改的日期无需创建空记录。
- 记录用户可感知的变化、关键修复、最终参数、验证结果及待办；重复微调以当天最终状态为主，必要时说明方案被替代的原因。
- 区分“已实现”“已验证”“待真机验证”，不把编译通过视为真实设备功能通过。
- 不改写前一天的历史状态；后续修复或参数变更记录在实际修改当天。
- 回溯内容依据会话和现有 notes；无法确认精确日期时明确注明，不凭文件修改时间编造逐项完成时间。
- 此约定随项目修改维护，不代表已设置后台定时任务。
